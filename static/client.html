Phone can't connect?
  1. iPhone with Chrome, Firefox, Edge or Brave: open Settings → Privacy & Security → Local Network and turn it on for that browser. Safari doesn't need this.
  2. Check the phone is on the same Wi-Fi. In its Wi-Fi details, its IP address should start with the same numbers. Turn off mobile data to be sure.
  3. Turn off any VPN or ad-blocking app on the phone.
  4. Allow the app through this computer's firewall.
  5. Clinic or guest Wi-Fi often stops devices reaching each other. Turn on the phone's hotspot and join this computer to it; this screen updates with the new address.
