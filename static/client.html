Phone can't connect?

  1. iPhone with Chrome, Firefox, Edge or BraveSettings → Privacy & Security → Local Network: turn it on for that browser. Safari doesn't need this.
  2. Same Wi-FiThe phone's IP address should start with the same numbers. Turn off mobile data to be sure.
  3. VPN or ad blockerTurn off any VPN or ad-blocking app on the phone.
  4. FirewallAllow the app through this computer's firewall.
  5. Clinic or guest Wi-FiThese often block devices from reaching each other. Turn on the phone's hotspot and join this computer to it; this screen updates with the new address.
